# 성모 PK ⚽🧤 — 초등학생을 위한 승부차기 게임

`성모 사커`와 같은 팀 · 유니폼 · 소리로 만든 **승부차기(PK) 게임**입니다.
HTML 한 장(`Index.html`)과 구글 Apps Script(`Code.gs`)로 만들어서, **구글 시트에 랭킹이 저장되는 웹 앱**으로 바로 배포할 수 있습니다.

- 태블릿 · 휴대폰(터치), 컴퓨터(마우스 · 키보드) 모두 지원
- 키커 뒤에서 골대를 바라보는 화면, 골 · 선방 · 골대 맞는 소리와 꽃가루 효과
- 처음 하는 친구를 위한 손가락 안내, 쉬운 말로 된 안내 문구
- 랭킹: **오늘 / 전체**, 닉네임마다 가장 높은 점수만 (한 사람이 랭킹을 다 차지하지 않게)
- 닉네임 고운 말 검사 (화면과 서버 모두)

## 게임 방법

| 차례 | 하는 방법 | 키보드 |
| --- | --- | --- |
| ⚽ 내가 찰 때 | ① **골대를 눌러** 찰 곳을 정하고 ② 힘 게이지가 **초록색**일 때 **슛!** | `←↑↓→` 조준 · `Space` 슛 |
| 🧤 내가 막을 때 | 상대가 공을 **차는 순간**을 보고, 공이 가는 곳을 **눌러서** 몸을 날려요 | `←` `→` 옆 · `↑` 점프 · `↑`+`←` 위 구석 · `Space` 가운데 |

- 두 팀이 번갈아 **5번씩** 차고, 같으면 **서든데스**.
- 너무 세게 차면 공이 뜨고, 너무 약하면 골키퍼가 쉽게 막아요. 구석은 막기 어렵지만 빗나갈 수 있어요.
- 골키퍼일 때 **너무 일찍** 움직이면 상대가 반대쪽으로 찰 수 있어요(보통 · 어려움). 차기 직전 키커의 **몸이 기우는 쪽**이 힌트!
- 점수 = (골 × 100 + 선방 × 100 + 승리 300) × 난이도 배율 (쉬움 ×1 · 보통 ×1.5 · 어려움 ×2)

| 난이도 | 내 슛 | 상대 골키퍼 | 상대 키커 |
| --- | --- | --- | --- |
| 쉬움 | 초록 구간이 넓고 게이지가 느림, 공이 날아갈 길 미리 보기 | 느리고 잘 못 읽음 | 공이 느리고 가끔 실축 |
| 보통 | 보통 | 30% 정도 방향을 읽음, 같은 쪽 습관도 읽음 | 일찍 움직이면 절반은 반대로 |
| 어려움 | 초록 구간이 좁고 게이지가 빠름 | 빠르고 잘 읽음 | 빠르고 구석, 일찍 움직이면 거의 반대로 |

## 파일

| 파일 | 내용 |
| --- | --- |
| `Index.html` | 게임 전체 (화면 · 그림 · 소리 · 규칙). 혼자 열어도 동작합니다(오프라인 모드). |
| `Code.gs` | Apps Script 서버: 웹 앱 열기(`doGet`), 기록 저장(`savePkResult`), 랭킹(`getPkLeaderboard`), 관리 함수 |
| `appsscript.json` | Apps Script 설정 (시간대 `Asia/Seoul`, 웹 앱 공개 범위) |
| `test/` | 개발용 자동 테스트 (Apps Script 에는 올리지 않아도 됩니다) |

## 구글 Apps Script 로 배포하기

1. **구글 시트**를 새로 만들고, 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
   (이 시트에 `PK랭킹` 탭이 생기고 기록이 쌓입니다. 시트 없이 [script.google.com](https://script.google.com) 에서 새 프로젝트로 만들어도 되며, 그때는 처음 저장할 때 `성모 PK 랭킹` 시트가 자동으로 만들어집니다.)
2. 편집기의 `Code.gs` 내용을 지우고, 이 저장소의 **`Code.gs`** 내용을 붙여 넣습니다.
3. 파일 옆 **＋ → HTML** 을 눌러 이름을 **`Index`** 로 만들고(`.html` 은 자동), **`Index.html`** 내용을 붙여 넣습니다.
4. (권장) **프로젝트 설정(톱니바퀴) → "편집기에서 appsscript.json 매니페스트 파일 표시"** 를 켜고, `appsscript.json` 내용을 붙여 넣습니다. 시간대가 한국 시간이 되어 **오늘 랭킹**이 정확해집니다.
5. 위쪽 함수 목록에서 **`setupPk`** 를 고르고 **실행** → 권한 허용. 실행 로그에 랭킹 시트 주소가 나옵니다.
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (아이들이 구글 로그인 없이 할 수 있게) — 학교 계정만 쓰려면 *조직 내 모든 사용자*
7. 나온 **웹 앱 URL** 을 아이들에게 나눠 주거나, 태블릿에서 열고 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다. 구글 사이트도구에 끼워 넣기(삽입 → URL)도 됩니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 웹 앱에 반영됩니다.

### clasp 를 쓰는 경우 (선택)

```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "성모 PK"   # 또는 clasp clone <스크립트 ID>
clasp push          # .claspignore 덕분에 Code.gs · Index.html · appsscript.json 만 올라갑니다
clasp deploy
```

## 컴퓨터에서 바로 해 보기 (오프라인 모드)

`Index.html` 을 크롬 · 엣지로 열면 바로 할 수 있습니다. 이때는 구글 서버가 없으므로 기록이 **이 브라우저에만** 저장되고, 랭킹 화면에 *오프라인* 이라고 표시됩니다.

## 선생님 · 관리자용

- **기록 초기화**: Apps Script 편집기에서 `clearPkRecords` 실행 (또는 시트 메뉴 **성모 PK → 기록 초기화**). 지금 기록은 `PK랭킹_백업_날짜` 탭으로 복사된 뒤 비워집니다.
- **기록 보기 · 지우기**: 구글 시트 `PK랭킹` 탭에서 바로 보거나, 줄을 지우면 됩니다. (랭킹 화면은 최대 30초 캐시)
- **다른 시트에 저장**: 프로젝트 설정 → 스크립트 속성에 `SHEET_ID` = 시트 ID 를 넣으면 그 시트에 저장합니다. `성모 사커` 와 같은 시트를 써도 탭 이름(`PK랭킹`)이 달라 섞이지 않습니다.
- **닉네임 필터**: `Index.html` 과 `Code.gs` 의 `BAD_WORDS` 목록에 단어를 더하면 됩니다 (두 파일 모두).
- **난이도 조정**: `Index.html` 의 `DIFFS` 표 (게이지 초록 구간, 골키퍼 반응, 상대 슛 속도 등). 점수 배율 `DIFF_MULT` · `PTS` 를 바꾸면 `Code.gs` 도 같이 바꿔 주세요.
- **팀 이름**: `Index.html` 의 `TEAMS` 와 `Code.gs` 의 `TEAM_NAMES` 를 같이 바꿔야 기록이 저장됩니다.

### 개인정보 안내

랭킹에는 **닉네임 · 팀 · 점수 · 시간**만 저장됩니다. 웹 앱을 *모든 사용자* 로 공개하면 랭킹도 주소를 아는 누구나 볼 수 있으니, 아이들에게 **실명 대신 별명**을 쓰도록 안내해 주세요.

## 개발 · 테스트

```bash
npm install                       # playwright (브라우저 테스트용)
npx playwright install chromium
npm test                          # Apps Script 가짜 환경 테스트 + 브라우저 테스트
```

- `test/gas.test.js` — `Code.gs` 를 가짜 Apps Script 환경에서 실행: 저장 · 검증 · 수식 주입 · 랭킹 · 캐시 · 초기화, 그리고 **화면과 서버의 점수 · 규칙이 같은지** 확인
- `test/game.test.js` — 실제 브라우저에서 한 판 끝까지, 터치 조준 · 다이빙, 키보드 · 일시정지 확인
- 브라우저 콘솔의 `window.__pk` 로 게임 상태를 보거나 시간을 돌릴 수 있습니다 (예: `__pk.state`, `__pk.sim(1)`).
